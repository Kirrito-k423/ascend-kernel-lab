# 昇腾接口微基准

## 定位资料

解析本 skill 真实源目录，向上两级找到本仓。读 [当前状态](../../README.md)、[实验设计](../../docs/benchmark-design.md)、[数据契约](../../docs/data-contracts.md)，使用 [实验模板](../../templates/experiment.md)。运行器未实现时，为当前问题先实现最小闭环；模板不是已完成的 NPU 实验。

## 工作流程

1. 将疑问改写成可证伪问题，明确功能、限制、延迟、吞吐或竞争，保存判定标准，避免看数据后改假设。
2. 调查芯片、CANN、工具链和 API 精确签名。优先本地对应头文件与官方文档，记录支持范围，不套用其他型号约束或频率。
3. 设计最小功能实验与可信 oracle。定义输入、输出、合法/非法边界和误差，检查容量及结果可观察性，防止优化删掉被测操作。
4. 先单核单卡基线，再单变量扫描，拐点附近扩组合；限制规模，保存种子与运行次序。
5. 发射、完成、稳态吞吐和 Host 端到端分开。复用验证后的时钟，加入空计时/循环/同步对照，确认异步完成后结束完成计时。
6. DataCopy 明确方向、重载、dtype、payload、shape、对齐、gap、pitch。字节表达意图后换算 API 参数，区分块头相隔512B与块后跳过512B。
7. GatherMask 覆盖固定/自定义、输出数量、顺序、稀疏度、reduceMode、repeat、stride；按文档核对 rsvdCnt，不检查未定义区域。
8. 多卡先确认 peer、通信后端和内存归属。分别跑单卡多核、多卡各本地、远端共享目标，记录竞争窗口；不将无序同址写用作正确性实验。
9. 小样本正确后再预热、多轮采集。保存失败、超时、全样本和设备状态，不删除慢样本以改善结果。
10. 输出分布、p50/p95、波动与有效字节吞吐，保留原始计时。缓存、编译和插桩是解释条件；无证据时物理总线流量未知。
11. 形成知识卡：发现、条件、命令、证据、置信程度、未决问题、实际应用。优化建议在真实算子复测，孤立 API 提升不等于端到端收益。

## 失败与结果边界

- 正确性失败：保存并缩小复现，停止该配置的性能结论。
- 不支持配置：记录官方/编译/运行证据，不作为极慢样本。
- 设备或网络不可用：调查已有可用环境和连接方式；最终记录具体阻塞、命令和未实测状态。
- 时钟、同步、单位不明：先解决测量有效性，再发布数值。
- 多卡没有共同时间窗口，不相加各 rank 峰值宣称总带宽。
