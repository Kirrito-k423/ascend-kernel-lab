# API Micro-benchmark 设计

## 实验循环

问题 → 官方签名与限制 → 最小正确性 → 参数矩阵 → 环境探测 → 采样 → 分析 → 知识卡 → 真实算子复验。

case 分离 spec、kernel、Host、oracle、报告。通用运行器管理环境、超时、种子、预热、重复、样本与失败；适配器负责合法性、内存及同步。计时复用 Trace 后端，但基准可只在整个循环外计时，避免每次调用插桩。

## DataCopy 第一批矩阵

先单变量，再围绕拐点加密。

| 轴 | 候选值或策略 |
| --- | --- |
| 方向 | GM→UB、UB→GM；其他路径独立适配 |
| payload/block | 32、64、128、256、480、512、1024 B，先检查合法性 |
| block 数/shape | 1、4、16、64，按 UB 容量裁剪，记录总有效字节数 |
| 基址偏移 | 0、32、64、128、256、480 B；非法配置单列能力边界 |
| gap | 0、32、512 B；前块尾到后块头 |
| pitch | 512、1024 B；相邻块头到头，pitch≥payload |
| 工作集 | 小工作集复用、扩大工作集、缓存策略；“冷”需证据 |
| 并发度 | 1、2、4、…、可用 AIV；固定总量与固定每核量分别测 |

读32B且 pitch=512B，gap=480B；读512B后跳过512B，pitch=1024B。两者不能都叫“跳跃512B”。记录原始 API 参数与字节语义，按具体重载换单位，不混用 DataCopyPad 与 DataCopy。

## GatherMask 第一批矩阵

固定/自定义 mask，全选/全不选/交替/随机/连续块，稀疏度、dtype、输入长度、reduceMode、repeat、stride。合法组合按部署版本确定。检查元素顺序、输出数量（含 rsvdCnt 语义）和边界，不对未定义区域编造期望值。

## 计时边界

- 发射耗时不称为 DMA/Vector 完成时间。
- 完成延迟排除前序工作，在操作完成且标量可观察后读时钟；同步实现绑定版本。
- 稳态吞吐测多次操作整体完成；依赖链延迟与独立流水吞吐分开。
- Host 端到端单列，注明 launch、同步、传输、导出包含项。
- 空循环/同步/计时作为对照，同时保留原始值，不盲减得到负时延。
- 短操作增加重复并测斜率，不能将单 tick 当作纳秒精度。
- 消费结果、检查生成指令，防止编译器删掉实验；循环需明确数据依赖。

## 多卡竞争

| 场景 | 测量对象 | 条件 |
| --- | --- | --- |
| 单卡多 AIV 本地 GM | 共享 L2/HBM 或本地资源 | 相同地址只读与分区写分开 |
| 多卡各自本地 GM | 系统干扰基线 | 不声称访问同一 HBM 控制器 |
| 多卡同一目标窗口 | 远端链路与目标内存 | 验证 peer 映射、SHMEM/HCCL/实际通信路径 |

记录 rank→设备、链路、内存归属、读写比例。先单卡/单对端，再 fan-in/out、双向。起跑同步定义竞争窗口，不能推导跨卡绝对时钟。无序同址多写不作为正确性基准，使用分区写、支持的原子或明确协议。

## 指标与知识卡

保留样本、预热、次序、重复、种子、超时与错误。报告分布、p50/p95、跨轮波动；多轮或成对随机顺序避免只挑最快值，小样本说明分位数局限。

有效吞吐=有效 payload/完成时间，不能用地址跨度当作搬运量。没有计数器证据，物理总线流量未知。读写总量、单向量和聚合口径分开；没有共同墙钟窗口不能把各 rank 峰值直接相加。

知识卡包含发现、范围、命令、证据、置信程度、未决问题和真实算子应用。正确性失败、环境不明、计时边界不明的结果不进入推荐结论。
