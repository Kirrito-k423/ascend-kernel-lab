# 需求与验收标准

## 使用场景

调试真实通算融合算子的进入偏晚、等待、搬运、通信完成与负载不均；持续验证接口功能、配置边界与性能，将结论用于真实算子。

## Kernel Trace

| 编号 | 要求 | 验收证据 |
| --- | --- | --- |
| T1 | 与目标仓分离 | 两个最小目标工程按固定版本接入，无业务头文件和 workspace 偏移依赖 |
| T2 | 原始时间戳 | 64位 tick、run/launch/rank/device/core/subblock/sequence/event/有效性完整 |
| T3 | 展示各 AIV 起点差异 | 验证时钟域后，用注入延迟探针检查还原，首点位于被观测同步之前 |
| T4 | 发射与完成分开 | DataCopy 和 Vector 明确同步路径、空边界对照与结果校验 |
| T5 | 离线分析出图 | 原始数据可重建 PNG/SVG、HTML、Perfetto/Chrome Trace JSON、摘要 CSV |
| T6 | 扰动有证据 | 关闭、空打点、采集开启对照，报告时间、UB/GM、导出成本 |
| T7 | 异常保留 | 缺失、溢出、丢弃与回绕有状态，不变成零耗时 |
| T8 | 运行隔离 | 多 stream、launch、进程不覆盖日志，不复用未完成 buffer |

## API Micro-benchmark

| 编号 | 要求 | 验收证据 |
| --- | --- | --- |
| B1 | 问题与参考结果 | 每例有假设、输入/输出及可信 oracle，错误结果不进入性能结论 |
| B2 | 可扩展 | case 描述、实现、验证、报告分离；新增 API 不改通用运行核心 |
| B3 | DataCopy | shape、方向、长度、对齐、pitch/gap、工作集、核数 |
| B4 | GatherMask | 固定/自定义、稀疏度、reduceMode、repeat/stride、输出数量与边界 |
| B5 | 竞争分类 | 单卡多核、多卡本地、跨卡共享目标分别记录拓扑与语义 |
| B6 | 统计可复核 | 全样本、预热、重复、种子、顺序、分布、p50/p95与字节口径 |
| B7 | 结论可复测 | 绑定芯片、软件、源码提交、编译选项、计时边界和原始结果 |

## 初版边界

优先一个已确认芯片/CANN 组合与 Ascend C SIMD，再扩 SIMT 和其他型号。多卡先确认地址可达和同步；本地 DataCopy 不自动等价于跨卡通信。跨卡不承诺无误差绝对时间，插桩不承诺无扰动。
