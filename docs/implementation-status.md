# 实现状态

## 已实现并上板

- 独立有界设备记录器：64位tick、每AIV独立存储、事件顺序、容量/丢弃/提交标志，模板关闭路径。
- 单进程单卡运行器：ACL资源管理、环境探测、参数检查、每launch记录、正确性oracle、开关采集对照、失败保留。
- DataCopy GM↔UB、多AIV连续与跨步搬运；GatherMask固定及自定义掩码。
- 离线原始数据校验、CSV统计、PNG/SVG、HTML配置选择、核内/未校准共同时间基准的Trace JSON。
- 大整数tick精度、缺失/损坏记录、非法参数、跨步oracle及矩阵唯一性测试。

## A5 接口实验补充

- CANN 9.1.0 / Ascend950DT_9582：长度对齐、SIMT 算术与调用开销、SIMD/REG 同工作量对照已独立完成实机验收，见 README 对应入口。
- 单卡多 AIV DataCopy 的共同 ACL Event 计时、独立 UB/GM 分区、14 档核数、4 种 tile/batch 与 1/2GiB 工作集已完成两轮、9072 个计时样本。当前到 64 核仍增长，未证明硬件带宽平台。
- 逐核 SYS_CNT 用于核内 DMA 区间；共同 ACL Event 不要求把未校准跨核绝对时钟拼接。通用跨核时钟映射仍未完成。

## 明确未完成

- 跨核时钟映射的严格校准，跨卡时间对齐。
- 真实业务算子仓接入验收及其性能回归；当前实机对象为本仓两个micro-kernel。
- 任意事件表的通用分析、嵌套span、采样环形buffer、生产级多流与图捕获适配。
- 多卡竞争、通用跨 kernel 异步稳态吞吐、冷缓存、更多dtype及完整API合法性边界。
- 精确隔离设备插桩开销：现有成对Host对照包含调度和launch噪声。
- 完整指令级反汇编核对：本机工具可提取设备ELF，但反汇编器显示not available；不声称已检查每条指令。通过多种循环次数的实测增长检查重复工作是否保留。

原始实现规划保留于roadmap，各大里程碑不得因最小闭环通过而全部勾选。
