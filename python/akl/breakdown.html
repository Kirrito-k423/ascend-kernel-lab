同类型耗时与 E2E 占比

完整语义路径相同的区间累加（该点至同核下一点）。E2E 为该 core 保留记录的首末点跨度，不代表完整 kernel 延迟。末点不计耗时，父子路径不重复累加。

平均视图按有至少两个打点的 core 等权平均，缺少的类型计 0；占比为平均类型耗时 ÷ 平均 E2E。少于两点的 core 显示 N/A 并排除。

此处统计全量保留区间，不随时间线缩放、block 筛选或显示换算变化；PNG 单位由解析时的 --clock-mhz 决定（未指定则为 cycle）。
